## What is Version Control?
Version control also known as source control or revision control, it is the practice of tracking and managing changes to a software code and other files. it allows software developers to see the entire history of who changed what at any given time. 

## Difference between Git and GitHub
Git is a distributed version control system built to help develpers track and manage changes in thier code.
 while GitHub is the cloud platform that hosts Git repositories where teams collaborate to build together.

## Explain the difference between Git fetch and Git pull
Git fetch command is used to fetch all changes from the remote repository to local repository. it doesn't make any changes to the current working directory.
 Git pull command on the other hand,is used to fetch all changes from the remote repository to the working directory. It automatically try to merge or rebase them into the current working directory

## Explain the simple terms git rebase and the command for it
Rebase is a Git action that allows users to mwrite the commits from one branch of Git to another. Command for it "Bash" it carries out the interactive rebase.

## Explain in simple terms Git cherry-pick and the command for it
Git cherry-pick allows you to apply a specific commit from one branch onto another without merging the entire branch. Command for it  *
